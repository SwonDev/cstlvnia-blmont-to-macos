# Dirección del README

La referencia explícita del usuario es d2r-mobile: presentar la experiencia instalada con capturas del juego, explicar cómo compilar e instalar y enlazar la metodología completa. La audiencia principal es quien quiere reproducir el resultado local en su Mac; la investigación de CI pertenece al registro técnico.

## Presentación

ENERGY 1, RHYTHM 2, MOTION 1. GitHub proporciona tipografía, colores, contraste y adaptación de tema. La identidad visual procede de las capturas reales de Castlevania, sin marcas inventadas, retoques, iconos decorativos ni métricas de rendimiento sin medir. Una imagen principal, pares comparables, pasos numerados, una tabla de adaptaciones y un diagrama del proceso. Detalles de reanudación y galería adicional plegables.

Todas las imágenes conservan texto alternativo y procedencia en GALERIA.md; capturas históricas y candidatas nuevas se distinguen. No se publican imágenes de otros juegos. Los límites funcionales siguen visibles, con pruebas y diagnósticos completos enlazados. El estilo se valida sobre el HTML que renderiza GitHub y los archivos originales; no hay interfaz web propia ni puntuación StyleSeed aplicable.
