# Registro de experimento

Plantilla para un fallo concreto; no es un resultado ya obtenido.

| Campo | Registro |
|---|---|
| Síntoma y reproducción | Sin determinar |
| Candidata/base: ejecutable y recursos | Sin determinar |
| Perfil/fixture y pantalla comprobada | Sin determinar |
| Hipótesis falsable | Sin determinar |
| Fuente primaria / contrato | Sin determinar |
| Única variable que se cambia | Sin determinar |
| Duración, repeticiones y presupuesto de evidencia | Sin determinar |
| Métrica y criterio de fallo fijado antes | Sin determinar |
| Hora inicial, muestras válidas y cobertura | Sin ejecutar |
| Resultado y evidencia | Sin ejecutar |
| Alternativas descartadas / no descartadas | Sin determinar |
| Prueba de regresión antes/después | Sin ejecutar |
| Instrumentación retirada y binario reidentificado | Sin ejecutar |
| Residuos retirados / evidencia retenida | Sin ejecutar |

## Interpretación

Separar observación, inferencia y causa demostrada. Registrar si el observador altera el timing. Un ensayo que no alcanza la pantalla objetivo, no tiene muestras o ejecuta un binario anterior queda invalidado; no cuenta como una mejoría.
